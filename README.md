# 📋 IT Notebook Booking System

ระบบจองเปลี่ยน Notebook สำหรับพนักงาน — IT Support

## ✨ Features

- **จองเครื่อง** — กรอกข้อมูลพนักงาน, เลือกเครื่องปริ้น, เลือกข้อมูลที่ต้อง Backup
- **Dashboard (Admin)** — ดูสถิติ, จัดการสถานะ, Export Excel, Calendar view
- **นัดหมาย** — พนักงานค้นหาชื่อเพื่อเช็คสถานะ และนัดเวลารับเครื่อง

## 🛠️ Tech Stack

- HTML5 / CSS3 (Glassmorphism design)
- Vanilla JavaScript
- Supabase (Backend/Database)
- FullCalendar.js (Calendar view)
- SheetJS (Excel export)

## 📖 Usage

เข้าใช้งานได้ที่ GitHub Pages URL ที่ deploy ไว้

| หน้า | URL |
|------|-----|
| จองเครื่อง | `/index.html` |
| นัดหมาย | `/appointment.html` |
| Dashboard (Admin) | `/dashboard.html` |
